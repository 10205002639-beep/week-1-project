# Week 01 PHP Exercises - Full Stack Web Development

Ten PHP exercises covering variables, arrays, conditions, loops, functions and readable HTML output.
All data is fictional.

## How to run
1. Copy this folder into the XAMPP document root (`C:\xampp\htdocs\`).
2. Start Apache in the XAMPP Control Panel.
3. Open `http://localhost/week01-php-exercises/exercise01/` (change the number for each exercise).

## Exercises
| # | Topic |
|---|-------|
| 01 | Fictional citizen profile |
| 02 | Age and service eligibility |
| 03 | Household member summary |
| 04 | Dzongkhag service counter |
| 05 | B-PIS record search |
| 06 | Profile validation engine |
| 07 | Service fee calculator |
| 08 | Role permission checker |
| 09 | B-PIS records report |
| 10 | B-PIS command dashboard (use the form at the top of the page to change dataset, filters, role and action) |
